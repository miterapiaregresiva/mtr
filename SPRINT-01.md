# Sprint 01 — Arquitectura, textos base y biblioteca secundaria

## Objetivo

Crear una nueva base para miterapiaregresiva.com orientada a:

- mejorar claridad y navegación;
- reforzar reputación y autoridad temática;
- facilitar tráfico orgánico;
- mantener la biblioteca como recurso secundario;
- preparar una estructura escalable para autores y libros.

## Criterios editoriales acordados

1. La biblioteca no es el eje de la web; funciona como colección de recursos para personas interesadas y como apoyo SEO.
2. La navegación principal prioriza terapia regresiva, método, trayectoria, preguntas, artículos y contacto.
3. Las fichas de autores son breves y editoriales.
4. Cada libro vive bajo su autor.
5. Una misma obra agrupa sus versiones por idioma.
6. Los enlaces a Internet Archive son externos; no se alojan copias de libros en el repositorio.
7. Se usan guiones en los slugs.
8. No se incorporan textos del tipo “aunque no está científicamente probado”.
9. No se publica una dirección fija; la información logística concreta se gestiona según el contenido acordado para la web y el contacto personal.
10. La biblioteca puede crecer sin ocupar peso visual dominante en portada o navegación.
